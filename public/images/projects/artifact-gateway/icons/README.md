# AWS Architecture Icons

Unmodified service icons from the official AWS Architecture Icons package, release 31 July 2026.

- Source and usage terms: https://aws.amazon.com/architecture/icons/
- Package: https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip
- Files: AWS Cloud Development Kit, Amazon S3, AWS Lambda, Amazon DynamoDB, Amazon CloudWatch (64 px SVG originals).

AWS owns these icons and associated marks. Their use follows the AWS Architecture Icons terms; the repository's MIT license does not grant rights to AWS trademarks or artwork.

The two parent diagrams embed these files as SVG data URLs so they render without third-party requests or external image dependencies. When updating an icon, update its embedded copies in the diagrams as well. All diagram labels stay in English across both site languages.
