# FiraCode Nerd Font

Source: FiraCode.tar.xz from the official Nerd Fonts v3.5.1 release:
https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1

The regular FiraCode Nerd Font TTF was converted to WOFF2 with fontTools, without subsetting. Programming ligatures and Nerd Font icon glyphs are preserved. The font is served locally; no font CDN is used.

Fira Code is by The Fira Code Project Authors, with Nerd Fonts patches by the Nerd Fonts contributors. See LICENSE.txt (SIL Open Font License 1.1) and UPSTREAM-README.md for the release's attribution and icon-set license information. The font is not covered by the repository's software license.
